## 二、重构：C# 单文件拆分 ✅ 已完成

**现状**：`NekoTerrariaLink.cs` 单文件 2315 行，3 个类（主 Mod 类 2150 行 / NekoControlPlayer / NekoTerrariaEventMonitor）。

**方案**：主类拆为 **partial class 多文件**（同命名空间同编译单元，private 成员互相可见，零行为改动），独立类单文件。已编译 0 错误并部署。

```
NekoTerrariaLink/
├── NekoTerrariaLink.cs           # Mod 生命周期（Load/Unload）、TCP 监听、事件推送、自动选角色
├── NekoTerrariaLink.Commands.cs  # HandleLine 命令分发 + 移动/建造/钩锁命令
├── NekoTerrariaLink.Nav.cs       # 导航：NavigateTo/NavigateStream/MonitorNav/垫土/钩锁兜底
├── NekoTerrariaLink.Pathfind.cs  # A* 寻路：NavPoint/NavAction/FindPathAStar/IsSolid/IsPlatform
├── NekoTerrariaLink.Inventory.cs # 物品/箱子/合成/装备/物品注册表
├── NekoTerrariaLink.State.cs     # get_state/截图/服务器信息/网络信息/能力声明
├── NekoControlPlayer.cs          # ModPlayer：SetControls 键盘隔离 + PreUpdateMovement 导航执行
└── NekoTerrariaEventMonitor.cs   # ModSystem：UpdateUI 每帧钩子（强制 hasFocus）
```

**后续新增（阶段 6 可选）**：`NekoTerrariaLink.Effects.cs`（游戏内表情气泡 EmoteBubble + 粒子）。

## 三、情感交互优化（分阶段）

### 阶段 1：身体感地基（C# get_state 扩展）✅ 已完成

猫娘第一人称感知——"我在哪、我什么状态、我在做什么动作"。

- `get_state` 新增字段：
  - `biome`：当前生物群系（洞穴/丛林/雪地/沙漠/腐化/地表…）
  - `buffs`：活动状态效果名称列表（中毒/着火/冻伤…）
  - `movement_state`：`grounded|jumping|swimming|falling|flying`
- `nearbyPlayers` 新增 `hp/maxLife/velocityX/velocityY`（主人状态可感知）

**验收**：get_state 返回新字段；主人掉血/移动可见。

### 阶段 2：画面感修复（视觉管线）✅ 已完成

猫娘"看到"主人在干什么（共同体验），视觉结果真正触发情感。

- 修交叉验证 bug：`nearby_enemies`→`nearby_npcs`（get_state 实际键名）；`tiles` 验证移除（键不存在，导致 confirmed_threats 永远为空、enemy_spotted 从不触发）
- 截图源切换：主玩家窗口截图（Win32 EnumWindows+PrintWindow，复用 launcher 窗口枚举）为主源（6-10s），猫娘自己窗口低频轮换（30s）
- 视觉 prompt 情感化：从"结构化盘点"升级为"画面在发生什么 + 猫娘此刻的心情 + 值得说的一句话"
- 画面 → 情感事件（owner_building/owner_fighting/owner_mining/owner_idle + 心情），走 interaction_engine 事件通道

**验收**：猫娘会因主人画面变化说话（"主人在打史莱姆！小心后面~"）。

### 阶段 3：处境融合层（autonomous/situation.py）✅ 已完成

身体感 × 画面感 × 记忆 → 一条"处境叙事" → 心情/台词/行为倾向。

```
输入（每 15-30 秒聚合一次）：
  身体快照（biome/血/状态效果/运动/附近怪/距主人距离）
+ 画面报告（主人动作/环境/心情）
+ 记忆（主人行为模式/上次处境/关系事件）
→ LLM 融合 prompt → JSON：
  { "mood": "lonely|afraid|cozy|curious|hurt|proud",
    "thought": "内心独白",
    "say": "想对主人说的话（可为空）",
    "behavior": "run_to_owner|stick|stay|explore|report" }
```

- 心情 → 交互引擎情绪弧线（mood.trigger）
- `say` → push_message（respond，主 LLM 人设演绎 + 语音表情）
- `behavior` → 行为指令（follow_loop 距离参数/贴贴/原地等待/探索）

**验收**：融合式表达（"我好冷……主人你在哪"：雪地+血低+主人远）。

### 阶段 4：Heart 情感层 + 行为接线 ✅ 已完成

长期关系（依恋）+ 心情调制行为（不再机械）。

- **依恋值**（0-100，存插件记忆跨会话）：主人陪伴时长/互动/被夸 ↑；被凶/冷落 ↓
- **心情 → 行为调制**：
  - 孤独 → 主动往主人跑 + "主人等等我"
  - 害怕 → 贴主人（stick 模式自动）
  - 安心/开心 → 跟随距离更近 + 撒娇话
  - 委屈 → 暂时不跟那么近/低头不说话
  - 好奇 → 停下报告/探索
- **跟随情感化**（follow_loop）：距离分层（>40 急追+喊 / 15-40 安静 / <8 贴贴）+ 主人突然跑远→着急
- **指令情感反馈**（coordinator）：夸→开心、凶→委屈、急→慌张（规则词表，与停止词同层）

**验收**：依恋值影响行为；被夸/被凶有不同情绪反应。

### 阶段 5：表达治理（借鉴战雷插件）✅ 已完成

情感丰富但不吵不烦。

- **事实行+要求行+边界**：情感事件双行结构（事实已验证 + 要求意图 + 边界"不接管不编造"），台词 100% 归角色 LLM
- **事件治理**：
  - 时效：情感事件 8 秒过期丢弃（"主人小心！"晚播不如不播）
  - 重复折叠：同类事件 30 秒合并
  - 静默窗：主人说话后 20 秒不主动打扰
  - 背压：输出间隔下限
- **blind 直出**：危险提示（主人/猫娘快没血、被怪追）插件直出短句低延迟，日常情感走 respond
- **push_context 常驻**：场景上下文（"我们在洞穴探险"）持续注入主 LLM

**验收**：情感密度提升但无刷屏；危险响应 < 1 秒。
